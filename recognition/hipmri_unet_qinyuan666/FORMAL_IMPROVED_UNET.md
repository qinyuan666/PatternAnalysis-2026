# Improved U-Net 正式训练与基线验证比较

两模型均已从头完成固定的 20 epochs。Improved U-Net 按最低验证 loss 选中第 **11** 轮，
训练计时 **66.70 分钟**。权重重载一致，660 张验证切片的病例评估已完成。
**以下全部是验证集结果；测试集尚未评估，不能据此声称已达到最终测试要求。**

## 设置与核验

沿用 [固定训练计划](TRAINING_PLAN.md)：11,460 张训练切片、660 张验证切片，
六类、前列腺 label 5、256×256 pad、base channels 16、batch size 4、
Adam 0.001、seed 3710、float32，不启用数据增强、不加载 pilot 权重。
除架构及输出位置外，两模型实验配置一致；共 57,300 次参数更新。
权重按验证 CE + foreground soft Dice loss 选择，不按前列腺 Dice 选择。
Improved U-Net 最佳 loss 为 0.415270；第 20 轮为 0.418586。

已核对完整的 20 轮历史、最低 loss 与保存轮次、权重 SHA256、数据清单哈希、
启动时源码哈希及当前源码。Case 评估重新合并后的像素指标与最佳验证记录完全相同。
日志只有已知的 CUDA cross-entropy 非确定性警告，没有训练或验证错误。
重载预测完全一致不代表重新训练能逐位复现。

## 相同预算下的验证结果

| 指标 | U-Net | Improved U-Net |
|---|---:|---:|
| 选中 epoch | 5 | 11 |
| 前列腺像素汇总 Dice | 0.8291 | 0.8320 |
| 前列腺像素汇总 IoU | 0.7081 | 0.7123 |
| 前列腺 Case 等权平均 Dice | 0.8090 | 0.7934 |
| 前景五类宏平均 Dice（像素汇总后） | 0.9061 | 0.9026 |
| 参数量 | 1,940,902 | 3,186,802 |
| PyTorch 峰值 allocated 显存（GiB） | 0.296 | 0.648 |
| 本次训练计时（分钟） | 51.70 | 66.70 |
| 单张模型推理中位数（ms） | 2.000 | 5.149 |

训练计时包含每轮验证与权重保存，不含初始验证及末尾重载/测速。
推理为 batch 1，5 次预热、20 次 CUDA 同步测量，不含读取和预处理；不是整病例耗时。
笔记本频率、功耗等条件未受控，因此时间只描述各次运行，不能作为可靠速度倍率。
Improved U-Net 峰值 reserved 为 0.855 GiB；上述显存不包括驱动和其他进程。
此前按单轮试跑估计的约 151 分钟是规划值，实际正式训练为 66.70 分钟。

| 身体 | 0.9813 | 0.9826 | 0.9657 |

补边参与 loss 和指标；背景高分不能用来证明器官分割质量。

| 验证 Case | 切片数 | U-Net 前列腺 Dice | Improved 前列腺 Dice |
|---|---:|---:|---:|
| Case 01 | 60 | 0.8666 | 0.8882 |
| Case 02 | 60 | 0.7645 | 0.7444 |
| Case 03 | 60 | 0.7586 | 0.6872 |
| Case 04 | 480 | 0.8465 | 0.8538 |

同一 Case 内所有周次和切片一起累计，再计算 Dice；不是 3D 体积重建或每次扫描的平均。
像素汇总会受各病例的目标像素数量影响，而等权平均给每个 Case 相同权重。
因此两种统计方式出现不同趋势并不矛盾：Improved 在 Case 01、04 提升，在 02、03 下降，
Case 03 下降最明显。其病例分数范围为 0.6872–0.8882，总体标准差为 0.0811。

**当前证据不支持“Improved U-Net 整体更好”。** 它的前列腺像素汇总 Dice 略高，
但病例均值、前景宏平均及膀胱 Dice 更低，同时参数和显存更多。
本次只有一个 seed 和四个验证 Case，不能推断统计显著性。
对当前前列腺任务，基线在病例均值及资源占用上更有优势，最终结论仍需固定测试评估。
原任务要求测试集前列腺 Dice ≥ 0.75，未明确指定聚合方式；这里透明报告两种方式。

![Improved U-Net 20 轮训练曲线](figures/real_improved_unet_20ep_curves.png)

训练 loss 持续降低，验证 loss 后期主要波动，提示继续训练未带来持续验证收益；
这与过拟合风险相符，但仅凭此曲线不能确定原因。训练指标在参数更新期间累计。
