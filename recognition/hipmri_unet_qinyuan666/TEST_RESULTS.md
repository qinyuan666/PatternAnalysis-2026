# 固定测试集结果：U-Net 与 Improved U-Net

两模型已用验证集选定的权重完成测试：**前列腺 Dice 在像素汇总和病例等权平均两种方式下均达到 0.75**。
评估覆盖原课程 test 划分的 540 张切片、3 个 Case、9 个 Case/week。
没有依据测试结果更换权重、调参、追加训练或重新划分数据。
本页完成测试 Dice/IoU 比较；整病例测速、边界指标与失败案例仍待完成。

## 固定方案与验证

[测试方案](TEST_PROTOCOL.md) 和评估代码在读取测试评分前提交于 `929bd24`。
U-Net 使用第 5 轮、Improved U-Net 使用第 11 轮权重，均来自独立的 20 轮正式训练，
按最低验证 CE + foreground soft Dice loss 选择。六类 argmax、256×256 pad、
逐切片归一化、batch size 4、CUDA float32；无增强、阈值搜索或后处理。

评估前后检查权重 SHA256 与冻结方案一致，清单、模型与预处理代码未改变。
两模型读到相同的病例、切片数及各类真实像素数。
从私有逐病例混淆矩阵重新计算的指标与公开汇总完全一致，
总计数为 540 × 256 × 256 = 35,389,440 像素（含补边）。
7 项病例评估测试、9 项指标测试和 3 项后台编排回归测试通过。

## 测试病例差异

别名只针对测试集；例如此处 Case 03 与验证报告的 Case 03 不是同一病例。
每个 Case 内合并全部周次和切片，不把不同周次当独立患者。

| 测试 Case | 切片数 | U-Net 前列腺 Dice | Improved 前列腺 Dice |
|---|---:|---:|---:|
| Case 01 | 420 | 0.8538 | 0.8538 |
| Case 02 | 60 | 0.8453 | 0.8119 |
| Case 03 | 60 | 0.8257 | 0.8562 |
| Case 等权平均 | 540（合计） | 0.8416 | 0.8406 |
| Case 总体标准差 | — | 0.0117 | 0.0203 |

所有三个病例都有前列腺标注，分数均有定义且均高于 0.75。
Case 01 两模型四位小数相同，但未舍入分数并不完全相等。
Improved 在 Case 02 下降、Case 03 提升；等权平均比基线低约 0.0010，差距很小。
像素汇总和病例平均的权重不同，不能事后仅选较高的聚合方式。
原任务没有明确指定 Dice 的聚合方式，本次两种方式都满足数值目标。
这只说明本次固定测试实验达到该项指标，不等于全部作业要求已完成。

## 结论与限制

Improved U-Net 在本测试集的像素汇总指标略好，但没有取得更高的前列腺病例均值，
病例分数离散程度也更大。结合此前参数量及显存记录，标准 U-Net 仍是资源受限场景下
合理的选择；不能据这三个病例、单个 seed 宣称任一架构具有统计显著优势。
当前证据不涉及临床有效性，也不能用重叠指标替代边界分析。

两模型最终测试结果保留原样，后续只补充冻结模型的边界、失败案例及资源分析。
若未来开展新模型开发，需要另行说明已查看此测试集及其评估局限。
物理空间单位仍未知，不能把像素距离报告为毫米。
