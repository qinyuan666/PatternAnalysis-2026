# U-Net 正式基线：20 epoch 实验

本次已从头完成 20 个 epoch，使用全部 11,460 张训练切片和 660 张验证切片。
**这份报告只包含验证结果，没有进行测试集模型评估。** 后续已完成同预算的
[Improved U-Net 验证比较](FORMAL_IMPROVED_UNET.md)，本页保留基线的详细记录。

## 设置与权重选择

采用已固定的 [训练计划](TRAINING_PLAN.md)：六类、前列腺 raw label 5、256×256 pad、
base channels 16、batch size 4、Adam 0.001、seed 3710、float32，不启用数据翻转增强。
沿用课程 31/4/3 个 Case 分组；每轮 2,865 次更新，共 57,300 次。
本次没有从 pilot 权重继续训练，也没有根据训练中的指标修改轮数或超参数。

按最低验证 CE + foreground soft Dice loss 选择 **第 5 轮**权重。
其验证 loss 为 **0.4174**；第 20 轮验证 loss 为 **0.4392**。
选择标准不是前列腺 Dice，因此报告使用所选权重的全部指标，不另挑某个类别最高的轮次。
权重重新加载后预测完全一致；这不保证重新训练逐位一致，CUDA cross-entropy 仍提示非确定性。
第 5 轮之后，训练 loss 总体继续下降，而验证 loss 没有再刷新最低值，说明增加轮数没有带来持续的验证改善。
这一现象提示需要关注过拟合，但单次实验不足以确定原因；本轮没有据此临时修改训练设置。

## 验证集结果

以下每类分数先在全部验证切片上累计像素混淆计数，再计算 Dice/IoU：

| 类别 | 像素汇总 Dice | 像素汇总 IoU |
|---|---:|---:|
| 背景 | 0.9991 | 0.9982 |
| 身体 | 0.9813 | 0.9632 |
| 骨骼 | 0.9262 | 0.8626 |
| 膀胱 | 0.9054 | 0.8271 |
| 直肠 | 0.8886 | 0.7996 |
| 前列腺 | 0.8291 | 0.7081 |

前景五类平均 Dice 为 **0.9061**。
补边参与 loss 和指标，尤其增加背景像素，不能将背景高分解释为器官轮廓质量。

逐 Case 评估将每个 Case 内所有周次和切片合并：

| 验证 Case | 切片数 | 前列腺 Dice | 前列腺 IoU |
|---|---:|---:|---:|
| Case 01 | 60 | 0.8666 | 0.7645 |
| Case 02 | 60 | 0.7645 | 0.6188 |
| Case 03 | 60 | 0.7586 | 0.6110 |
| Case 04 | 480 | 0.8465 | 0.7339 |

4 个 Case 等权平均前列腺 Dice 为 **0.8090**，
范围 **0.7586–0.8666**。
作为对照，单轮 pilot 的 Case 平均为 **0.7044**。
这是一组 seed 下的验证比较，不是独立测试、统计显著性结论或临床有效性证据。
原任务 PDF 第 6 页要求测试集前列腺 Dice ≥ 0.75，未明确指定平均方式；这里同时报告两种聚合方式。

训练曲线的训练指标在参数更新过程中累计，不能直接视作最终模型在训练集上的重新评分。

## 资源与复核

- 参数量：1,940,902。
- 训练、每轮验证与保存权重合计：**51.70 分钟**；不含初始验证、末尾重载检查与推理测速。
- 峰值 PyTorch allocated：**0.296 GiB**；reserved：**0.420 GiB**；不含其他进程与驱动显存。
- 单张模型推理中位数：**2.000 ms**，5 次预热、20 次同步测量，不含数据读取与预处理；不是整病例推理时间。
- 逐 Case 评估再合并后的像素指标，与训练时保存的最佳验证指标完全一致。

本次笔记本运行时 GPU 频率/功耗有变化，因此耗时是该次实际观察，不能当成两模型的受控速度比较。
完整配置、每轮分数、代码/清单/权重哈希见 [训练汇总](results/formal_unet.json)
与 [病例评估](results/formal_unet_cases.json)。

## 本机输出与复现

以下文件位于本项目目录下，被 Git 忽略：

- `runs/real_unet_20ep_s3710/best.pt`：所选权重。
- 同目录 `summary.json`、`config.json`、`console.log`：完整运行记录。
- `case_validation/summary.json` 与 `case_details_private.json`：汇总指标及私有病例映射/混淆计数。
- `case_examples/prostate_examples.png`：四个病例的 MRI、前列腺真实标注、预测、误差叠加图。

示例在每个验证 Case 的前列腺阳性切片中，按真实标注面积取排序后的下中位数，
同面积按清单顺序决定；不根据模型预测挑选。白色表示前列腺，误差列红色为误报、蓝色为漏报。
这是四张选定阳性切片的展示，不是完整的边界失败案例分析，也不代表所有切片的效果。
原始病例编号、MRI 示例和权重保留在本机；GitHub 只收录汇总数据与不含 MRI 的统计图。

复现命令见训练计划，使用新的输出目录（例如 `runs/real_unet_20ep_s3710_reproduce`）。
评估时使用同一版本的 `course_v1.csv`，其哈希必须与权重一致。
